# Weather App (React)

Search any city and see its current weather, using the OpenWeatherMap API.

## Run locally
1. npm install
2. Create a .env file with: REACT_APP_WEATHER_KEY=your_api_key
3. npm start

Live demo: <[Open the app](https://weather-app-react-5lrnrgo37-vinothrstar1111-6165.vercel.app/)
